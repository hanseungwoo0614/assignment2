# 9주차 실습 2 · 검색·정렬·페이지네이션 게시판 개선

## 실행 방법

Node.js 18 이상이 필요합니다. (`node_modules` 는 저장소에 포함하지 않았습니다.)

```bash
npm install        # 의존성(express) 설치
node server.js     # 서버 실행
```

브라우저에서 http://localhost:3000 에 접속합니다.

자동 테스트는 서버를 따로 켜지 않고 실행할 수 있습니다.

```bash
npm test
```
